# HL1CSharp
 C# Implementation of server and client libraries of Half-Life 1 to work with Xash3D  
 Uses C#'s code generation to generate entry points for spawning C#-written entities  
 Uses .NET AOT compilation, so the engine could load the libraries. .NET's AOT supports only x64 devices, so it cant be used with original GoldSrc, only with Xash3D   
 Written by me in Q3 2025
